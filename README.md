# Fra design til kode

Denne README.md filen sier noe om Refleksjon og også dokumentasjon

## Dokumentasjon

Jeg lagde nettsiden med HTML, CSS og JavaScript. Jeg tok utgangspunkt i designet fra Figma og lagde en enkel prototype med forside, nyhetsside og diskusjonsside.

Jeg brukte HTML for innholdet, CSS for design og JavaScript for funksjoner. Nettsiden har blant annet navigasjon, bilder, liker-knapper og et kommentarfelt.

Jeg brukte CSS Grid og media queries for at nettsiden også skal fungere på mobil. Jeg brukte samme CSS-fil og JavaScript-fil på sidene for å slippe å skrive den samme koden flere ganger.

## Refleksjon

Jeg synes det gikk greit å lage nettsiden, men jeg hadde noen vanskeligheter og fant ut at det var bedre å ta utgangspunkt i figma designet og lage en nettside versjon, siden den var litt dårlig.

Jeg synes jeg fikk med det viktigste fra Figma-designet. Bildet av im komboen mangler, men det går bra. Jeg lærte også mer om hvordan HTML, CSS og JavaScript fungerer sammen.

Hvis jeg skulle jobbet videre med nettsiden, ville jeg gjort designet mer likt Figma og lagt til en database. Da kunne kommentarer og brukere blitt lagret.
